# Challenge 01 - Count Vowels

**Difficulty:** Easy

## Description

Create a function called `countVowels` that counts the number of vowels in a given string.

Vowels consist of:

`a, e, i, o, u`

The function must be case-insensitive.

## Requirements

1. Create a function named `countVowels`.
2. Accept one string as its parameter.
3. Count all vowels in the string.
4. Both uppercase and lowercase vowels must be counted.
5. Return the total number of vowels.
6. Ignore spaces, numbers, and punctuation.

## Examples

| Input          | Expected Output |
| -------------- | --------------: |
| `"hello"`      |               2 |
| `"javascript"` |               3 |
| `"HELLO"`      |               2 |
| `"OpenAI"`     |               4 |
| `"rhythm"`     |               0 |
| `""`           |               0 |

## Constraints

- Input will always be a string.
- The function must return a number.
- Do not use external libraries.
- Do not use `console.log()` as the function's return value.

## Learning Goals

- Practice string iteration.
- Practice conditional statements.
- Understand string character comparison.
- Practice writing and testing functions.

## Completion Criteria

All tests in `test.js` must pass.

**Do not look for a solution before attempting the challenge yourself.**

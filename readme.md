# JavaScript Challenges

This repository contains a set of beginner-friendly JavaScript exercises focused on core programming concepts such as strings, arrays, loops, conditionals, and testing.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the test suite:
   ```bash
   npm test
   ```

## Notes

Each challenge includes a problem description, requirements, examples, and completion criteria. The goal is to solve each task by writing the required function and making the tests pass.
